Plan for the TaskCore

Basic Functionality:

1. list all tasks
	- Name, pid, cpu usage in %, memory usage in value, process path
	- columns: Name, PID, CPU Usage (%), Memory Usage (MB), Process Path at top of the tree view

2. End task button
	- End task button should be display one time at the right bottom of the window after tree view 

3. Tree view of tasks
	- Expand/collapse functionality for parent processes

4. Auto refresh
	- Refresh tasks every 1 seconds

5. Run as administrator
	- Ensure the application has the necessary permissions to manage tasks

6. filter for memory usage
	- Allow users to filter tasks based on memory usage thresholds


Note: Application will be future proof like it will have tab veiw to cange from one functionality to another functionality like processlist and graph tab to chnage views easily.
